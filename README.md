Sunvale — an open-world crime game. Drive, steal cars, dodge the police and run Marla's missions across a living city: traffic, pedestrians, wanted stars, police chases, combat, and three story missions, all in vanilla JavaScript and canvas, fully offline.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Or open `game/index.html` directly.
